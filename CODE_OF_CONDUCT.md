# Code of conduct

This project adopts the **Contributor Covenant, version 2.1**, as its code of
conduct:
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.

It applies to everyone in every project space: issues, pull requests,
discussions, reviews, and any other channel used to work on the project, and
when someone represents the project elsewhere.

## Reporting

Report unacceptable behavior to the project maintainers privately through
GitHub: open the repository's **Security** tab, choose **Report a
vulnerability**, and start the title with `[Conduct]`. That creates a report
only the maintainers can read. You can also contact a maintainer directly
through their GitHub profile.

All reports are reviewed promptly and handled confidentially. Maintainers who
are involved in a report do not take part in handling it.

## Enforcement

Maintainers follow the Contributor Covenant's enforcement guidelines
(correction, warning, temporary ban, permanent ban), and may remove, edit or
reject comments, commits, code, issues and other contributions that do not
align with this code of conduct.
